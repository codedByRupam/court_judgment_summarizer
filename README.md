##  What It Does

Court judgments often contain dozens of pages filled with legal language.

This application automatically extracts and analyzes judgments to help users understand:

* What the case is about
* What each side argued
* How the court reasoned
* What the final verdict was

All within seconds.

---

##  Features

### Verdict Detection

Automatically identifies:

* Petition Allowed
* Petition Dismissed
* Appeal Allowed
* Appeal Dismissed
* Disposed Cases

---

### Smart Case Summary

Generate a concise 5-point summary highlighting the most important aspects of the judgment.

---

###  Detailed AI Summary

Uses Transformer-based NLP models to produce an easy-to-read explanation of the case.

---

### Structured Legal Analysis

The system extracts:

* Facts
* Petitioner Arguments
* Respondent Arguments
* Court Reasoning

making judgments easier to understand.

---

### Legal Entity Extraction

Automatically identifies:

* Judges
* Parties
* Dates
* Organizations
* Locations

from the judgment.

---

### Downloadable Report

Export the complete analysis in a single report.

##  Installation

Clone the repository:

```bash
git clone https://github.com/codedByRupam/court_judgment_summarizer.git

cd court_judgment_summarizer
```

Create virtual environment:

```bash
python -m venv venv
```

Activate:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
streamlit run app.py
```
